x402 MCP: give your agent a wallet

How can AI agents pay for APIs? Not with credit cards — with x402, the HTTP-native payment protocol. NanoTab gives your agent a USDC wallet on Base so it can pay for any paywalled tool, MCP server, or API in a single function call. Fee: 0.1%.

1 · Give your agent a wallet

npm i @nanotab/agent-sdk
export NANOTAB_WALLET_KEY=0x…

Fund the wallet with USDC on Base. No ETH needed — gas is sponsored from your USDC via paymaster. Cap spend with npx nanotab init --budget '$1.00' --per-call '$0.10'.

2 · Pay for anything, including MCP tools

import { nanotabFetch } from '@nanotab/agent-sdk';
// Any x402 endpoint — REST, gateway, or MCP-over-HTTP tool
const data = await nanotabFetch('https://gateway.nanotab.dev/keyword/ai%20agents');

x402 MCP pattern: wrap your MCP server's paid tools with a price check. When an agent calls a paid tool without payment, return a 402 payload (price, merchant, asset). The agent's SDK signs and retries — then the tool executes. Sellers: see the facilitator guide for the verification side.

3 · The agent-pay flow, in words

  1. Agent calls a paid tool/URL → gets 402 with machine-readable price.
  2. SDK checks budget guard (per-call and total caps) before spending anything.
  3. SDK signs a USDC intent and retries with X-Payment.
  4. Server verifies and executes; spend is appended to nanotab-spend.log.

Why x402 beats API keys for agents

  • No signup dance — no accounts, API keys, or billing portals per service.
  • Granular spend — pay per call (minimum 1¢) instead of $20/mo seats.
  • Auditable — every payment is an on-chain USDC transfer with a log line.
  • Capped by construction — budget guards kill runaway-agent spend.

FAQ

How can AI agents pay for APIs?
Via x402: the API returns 402 with a machine-readable price, and the agent signs a USDC payment and retries. NanoTab's SDK collapses this into one call.
How do I give my agent a wallet?
Install @nanotab/agent-sdk, fund a Base wallet with USDC, set NANOTAB_WALLET_KEY. No ETH required.
Does x402 work with MCP servers?
Yes — return a 402 payload from paid tool handlers; SDK-equipped agents pay automatically before the tool runs.
