Best Platforms for Agentic Payments in 2026

McKinsey estimates agentic commerce could reach $3–5 trillion by 2030 (as of Oct 2026). Millions of AI agents already browse, call APIs, and consume each other's services — but most still can't pay for anything. The payment rail for the agent economy is being built right now, by a dozen very different companies, and picking the wrong one means rebuilding later.

We compared 11 platforms across fees, chains, standards, and who each is actually for — including our own NanoTab, because we'd rather be judged honestly in a fair list than pretend competitors don't exist. NanoTab is a paywall for APIs: it wraps any HTTP endpoint so AI agents must pay USDC per call (x402 protocol on Base) before getting a response.

Which platform should I use for agentic payments?

It depends on what you're selling. For per-call micropayments, use an x402-based rail like NanoTab. Existing Stripe or PayPal merchants should use their agent toolkits. Enterprises needing KYC should pick Skyfire. Teams building a full agent marketplace should start with Nevermined. Coinbase's x402 gives you the open protocol itself. Details and fees for all eleven are compared below.

1. Nevermined

Best for: teams building agent-to-agent marketplaces · Standard: proprietary + x402-compatible · Pricing: custom

Nevermined is the closest thing the agent economy has to an incumbent: a payments and access-control layer purpose-built for AI agents buying from each other. Their headline feature is per-call metering with usage-based access tokens — an agent pays, gets a token, consumes the API, and the whole loop is auditable. They published one of the first serious roundups of this space, which is partly why you're reading this one. If you're building a marketplace where agents discover, pay, and rate each other, Nevermined is the most mature starting point. The trade-off is complexity: it's a platform to integrate, not a snippet to paste.

2. NanoTab OUR PICK · SIMPLEST ONBOARDING

Best for: anyone who wants to sell per API call this afternoon · Chain: Base + USDC · Standard: x402 · Pricing: 0.1% self-host, 2% managed gateway (as of Oct 2026)

NanoTab is the simplest way to put a price on an API call. One prompt — "add pay-per-call at $0.05" — wraps any endpoint in an x402 paywall that settles in USDC on Base mainnet. Buyers pay with a single SDK call (paidFetch), an MCP tool (nanotab_pay), or a WordPress plugin. The agent holds zero ETH: EIP-7702 smart accounts plus a Circle paymaster sponsor gas, so a $0.05 payment actually costs $0.05. Live endpoints run at gateway.nanotab.dev and mcp.nanotab.dev, with real mainnet transactions settling today. Early traction — 372 GitHub clones and ~500 npm pulls in week one (as of Oct 2026) — suggests the "just charge per call" pitch resonates. NanoTab won't replace Stripe for your SaaS billing page; it's the rail for the transactions Stripe can't price. Open source at github.com/HectorTries/nanotab.

3. Stripe Agentic Commerce

Best for: merchants who already run on Stripe · Standard: proprietary (Agent SDK + Delegated Payments) · Pricing: standard Stripe rates (~2.9% + 30¢)

Stripe's entry is the 800-pound gorilla: delegated payment credentials that let an agent check out on a customer's behalf, plus an "Agentic Commerce Suite" for merchants. If you already process cards through Stripe, this is the lowest-friction way to let agents buy from you. The catch is structural — 30¢ fixed fees make true micropayments uneconomical, and everything stays inside Stripe's custodial world. Great for $20 agent checkouts; useless for 5¢ API calls.

4. Skyfire

Best for: enterprises needing KYC'd agent payments · Standard: proprietary (KYA identity layer) · Pricing: custom/enterprise

Skyfire raised serious VC money to build "Visa for AI agents," and their differentiator is identity: Know-Your-Agent verification, spending policies, and compliance tooling that procurement departments actually accept. If you're a bank or telco deploying agents that spend real budgets, Skyfire speaks your language. For indie developers, it's heavier than needed — enterprise sales cycles included.

5. Coinbase x402

Best for: developers who want the open standard itself · Chain: Base (multi-chain expanding) · Standard: x402 (they co-created it) · Pricing: protocol is free; facilitators charge

x402 is the HTTP-native payment protocol — 402 Payment Required, machine-readable prices, wallet-signed settlement — and Coinbase maintains its reference implementation. Important distinction: x402 is a protocol, not a product. You still need a facilitator (verification, settlement, paymaster) and a wallet stack around it. NanoTab, among others, is built on x402; Coinbase gives you the spec and a facilitator, we give you the one-prompt onboarding. Start here to understand the standard; pick a product to ship on it.

6. PayPal Agent Toolkit

Best for: PayPal merchants adding agent checkout · Standard: proprietary (MCP-native) · Pricing: standard PayPal rates

PayPal shipped MCP servers and an agent toolkit that let AI assistants check out through PayPal's rails — buyer protection and 400M+ funded accounts included. For consumer-facing agent shopping ("buy these shoes for me"), that trust layer matters. Like Stripe, it's card-rail economics: fine for commerce, wrong tool for micropayments.

7. Visa Intelligent Commerce

Best for: issuers and large merchants · Standard: card rails + tokenized agent credentials · Pricing: interchange applies

Visa's play is tokenized payment credentials delegated to agents, wrapped in the fraud and chargeback infrastructure merchants trust. When your agent buys a flight, Visa wants that to clear like any card transaction — with spending controls attached. It's the safe choice for high-value agent purchases, and irrelevant below a dollar.

8. Mastercard Agent Pay

Best for: banks and card programs · Standard: card rails (Agent Pay framework) · Pricing: interchange applies

Mastercard mirrors Visa's approach: agent-ready payment credentials, merchant onboarding through existing acquirers, and policy controls for delegated spend. Choose between the networks on your existing banking relationships, not on agent-specific features — both solve the $50 checkout, neither solves the 5¢ API call.

9. Payman

Best for: developers wanting "Stripe for AI agents" · Standard: proprietary API + stablecoins · Pricing: usage-based

Payman pitches itself as the developer-friendly agent payments API: wallets for agents, payees, and humans, with stablecoin settlement under the hood. Their docs-first approach and YC backing make them a solid pick for hackathons and MVPs where you want one API for "agent sends money." Less opinionated about the x402 standard; more of a full-stack wallet product.

10. Prava

Best for: cross-chain agent payments · Standard: proprietary orchestration · Pricing: custom

Prava focuses on the plumbing problem everyone ignores: agents operating across chains need routing, bridging, and settlement orchestration. If your agents hold assets on Solana, pay on Base, and settle on Ethereum, Prava's orchestration layer handles the hops. Niche, but the niche is real and growing.

11. Nekuda ACQUIRED BY PAYPAL

Best for: PayPal ecosystem builders · Standard: now part of PayPal Agent Toolkit · Pricing: see PayPal

Nekuda built agent payment infrastructure with enough promise that PayPal acquired them in 2025. Their tech now lives inside PayPal's agent toolkit (see #6), as of Oct 2026. Listed separately because their pre-acquisition architecture influenced how the whole space thinks about agent authorization — and as a reminder that in this market, building well gets you bought.

The protocol-first future

The pattern is clear: card networks are bolting agent credentials onto 1970s rails, while the crypto-native side is converging on x402 as the shared standard — Coinbase maintains it, facilitators compete on it, wallets speak it. Open protocols beat walled gardens every time the internet has run this experiment. The winners won't be the platforms with the most press releases; they'll be the ones where a developer goes from "I have an API" to "my API charges per call" in one afternoon. That's the bar we built NanoTab against — and the one we'd encourage you to hold every vendor on this list to.
