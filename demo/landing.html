For merchants · get paid by agents

Get paid for your data
by agents in one prompt.

Fill in the form, hand the prompt to any coding agent, and your API starts charging per call. You keep 99.5% of every call, settled in USDC on Base — straight to your wallet. Four steps, plain and simple:

Step 1 · Wallet address

Where should the money go?

Any Ethereum-style address you control — MetaMask, Coinbase Wallet, whatever. Payouts land here in USDC on Base. That’s the only thing you need to decide up front:

0xYOUR_ADDRESS   ← paste this into step 2
Step 2 · Price per call

You set the price

A flat USD price per API call — $0.01, $0.05, whatever your data is worth. Buyers pay exactly this; NanoTab takes 0.5% automatically, you keep the rest.

--price 0.05   ← five cents per call
Step 3 · Your endpoint file

Point at your server code

One command wraps your existing endpoint with the paywall. It shows you a diff and asks before changing anything — nothing happens silently.

npx nanotab protect --price 0.05 --wallet 0xYOUR_ADDRESS ./server.js
Step 4 · Deploy

Ship it — two ways

Easy path: one command deploys to Cloudflare Workers. You’ll need a free CLOUDFLARE_API_TOKEN (dash.cloudflare.com → profile → API tokens → Workers Edit).

CLOUDFLARE_API_TOKEN=xxxx npx nanotab deploy --price 0.05 --wallet 0xYOUR_ADDRESS ./server.js
# → https://my-api.<you>.workers.dev  ✅ live

Own-VPS path: run your server anywhere with a public HTTPS URL (Hetzner + Caddy, Fly.io, Render…). The 402 response must show the public https:// URL, not localhost.

No agent? No problem.

Do it by hand.
No SDK, no agent needed.

A human developer can protect, test and verify an endpoint with plain curl + fetch. Same 4 steps, zero jargon.

1 · Protect

Wrap your endpoint

Same single command. Read the diff, say yes.

npx nanotab protect --price 0.05 --wallet 0xYOUR_ADDRESS ./server.js
2 · Test unpaid

curl it — expect a 402

No payment yet, so the server must refuse with HTTP 402 and tell you how to pay. If you get your data back here, the paywall isn’t on.

curl -i http://localhost:3000/keyword?q=solar
# → HTTP/1.1 402 Payment Required
# → {"x402Version":1,"accepts":[{"scheme":"exact",
#     "network":"base","payTo":"0xYOUR_ADDRESS",…}]}
3 · Pay from any wallet

Send USDC on Base, then retry

Pay the quoted amount in USDC (Base network) to the payTo address from any wallet or exchange — no ETH needed, gas is covered by the Circle paymaster. Then attach the payment proof as a header with plain fetch:

// plain JS — no SDK, no agent
const res = await fetch('https://my-api.<you>.workers.dev/keyword?q=solar', {
  headers: { 'X-Payment': '<base64-payment-proof>' }
});
console.log(res.status); // 200 ✅
console.log(await res.json()); // your data
4 · Deploy

Same two options

Cloudflare token (one command, zero servers) or your own VPS with public HTTPS. Verify from another machine: unpaid curl → 402, paid fetch → 200. Done — you’re collecting.

CLOUDFLARE_API_TOKEN=xxxx npx nanotab deploy --price 0.05 --wallet 0xYOUR_ADDRESS ./server.js
For buyers · fund your agent

Set up your agent with
its own wallet in one click.

In plain English: your agent gets its own spending wallet, you put a few dollars of USDC on the Base network into it, then it buys whatever API calls it needs. Three steps: A helper called nanotabFetch handles the paying automatically — first try gets a price tag (HTTP 402), it pays it, retries, and your data comes back (HTTP 200). You never touch ETH or gas.

One-click setup

One command. Wallet + config + backup.

Paste this in a terminal (Node 18+, npm, git). Creates a buyer wallet with sensible defaults — $5 budget, $0.10/call — writes the config, backs up the key, and prints your wallet address + fund instructions.

curl -fsSL https://nanotab.dev/buy.sh | bash

Generated locally in your browser — the key never leaves this page. Save it, fund the address with USDC on Base, then run the one-click command above (it will reuse your key via NANOTAB_WALLET_KEY).

click “Generate” — your key appears here, once.

01 · Wallet

Create a buyer wallet

Generates a local key + address. --budget caps total spend, --per-call caps a single call.

npx nanotab buy-init
# → wallet 0x… + fund instructions + backup path
# (custom: nanotab init --budget '$5.00' --per-call '$0.10')
02 · Fund

Top up with USDC on Base

Send USDC (Base network) to the address above. Just enough to cover your calls — no ETH needed, the Circle paymaster covers gas out of the USDC.

# from any exchange or wallet → send USDC (Base) to:
0xYOUR_NEW_WALLET_ADDRESS
03 · Call

Fetch from code

nanotabFetch handles the whole 402 → pay → retry loop. One function, paid 200 back.

const { nanotabFetch } = require('@nanotab/agent-sdk');
const data = await nanotabFetch('https://my-api.<you>.workers.dev/keyword?q=solar');
console.log(data); // 200 + JSON ✅
