NanoTab wraps any HTTP API in a paywall. No API keys, no signup — the agent pays $0.02 in USDC, the merchant gets paid, NanoTab takes 0.5%.

Try the live gateway GitHub

How it works

1. Agent calls your API

No X-Payment header? Gateway answers 402 Payment Required with price, wallet & network.

2. Agent pays in USDC on Base

Agent signs a micropayment ($0.02/call) and retries with X-Payment: base64(proof).

3. Gateway verifies & proxies

Proof checks out → request proxies to your origin. You keep 99.5%. Zero code changes on your side.

Live demo

# 1 — no payment → 402 challenge
curl https://gateway.nanotab.dev/keyword/solar
# → {"x402Version":1,"accepts":[{...,"maxAmountRequired":"2",...}]}

# 2 — pay $0.02 (mock signature on testnet) → 200, real data
curl -H "X-Payment: <base64-proof>" \
  "https://gateway.nanotab.dev/keyword?q=solar"
# → {"term":"solar","volume":89625,"cpc":1.25,...}
